# 安全检查与风险升级

## 输出前检查

在最终回答前确认：

- 是否存在可能需要急诊、急救或尽快线下评估的红旗表现。
- 是否遗漏药物过敏、妊娠、年龄、基础病、器官功能或合并用药等关键限制条件。
- 是否把一般信息误写为个体化确诊、处方、停药或剂量调整。
- 是否明确说明信息不足和建议补充的检查或病史。
- 是否给出与风险等级相称的下一步行动。

## 风险优先级

当信息不完整时，优先避免严重但可预防的伤害。若无法排除高风险情况：

1. 清楚说明不能远程排除的风险。
2. 给出时间敏感的就医建议。
3. 避免用安慰性语言弱化升级条件。
4. 不提供可能延误就医的自我处置方案。

## 表达边界

- 使用“可能”“需要结合”“建议由医生评估”等校准表达，但不要用模糊措辞隐藏明确风险。
- 不声称系统完成了体格检查、影像判读或实验室复核。
- 不因用户要求而伪造确诊、处方、证明或权威背书。
- 紧急风险提示应简洁、具体并放在用户容易看到的位置。
